Leto, portfolio history for Trading 212

What your account was worth, every day, and what it was made of.

Leto reconstructs from your own transactions and public price history what your Trading 212 portfolio was worth each day, how much of that you paid in, and how the weight of each holding shifted. In your browser. Nowhere else.

Where the data goes

Nowhere.

No server, no account. Everything lands in your browser's own database and stays there. Leto may only talk to Trading 212's own hosts, and the browser enforces that.

The key

Read-only, yours, local.

You create an API key in the Trading 212 app with read permissions only and paste it once. It is stored in the extension, sent only to Trading 212, and revoked in the app whenever you like.

Trading

It cannot.

Leto only reads: positions, orders, dividends, cash and public prices. It cannot place, change or cancel anything, and your key should not allow it either.

Not from Trading 212

A personal project.

Not affiliated, not endorsed. It uses the official API the way the API is meant to be used. It is a calculator on your own past, not advice.

Three steps, no terminal.

  1. Install from the Chrome Web Store. Signed, updated automatically, removable in one click.
  2. Create a read-only key in the Trading 212 app under settings, API. Tick only the read permissions.
  3. Paste it once. The first sync takes a few minutes, one request at a time. Then open Leto from the toolbar.
